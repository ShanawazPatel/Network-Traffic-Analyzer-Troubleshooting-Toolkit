Linux Virtualized Local Network & Stateful Firewall Sandbox

Simulates a multi-node isolated virtual network using Linux network namespaces (ip netns), virtual ethernet pairs (veth), and kernel iptables / nftables stateful firewall rules enforcing routing policies, SYN-cookie flood mitigation, and packet filtering.

Active Firewall Ruleset (linux_lab/firewall_rules.sh)
# Default Policies
iptables -P FORWARD DROP
iptables -P INPUT DROP

# 1. Stateful Connection Tracking
iptables -A FORWARD -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A FORWARD -m state --state INVALID -j DROP

# 2. Stealth Scan Drops
iptables -A FORWARD -p tcp --tcp-flags ALL NONE -j DROP
iptables -A FORWARD -p tcp --tcp-flags ALL FIN,PSH,URG -j DROP

# 3. SYN Flood Mitigation
iptables -A FORWARD -p tcp --syn -m limit --limit 25/s --limit-burst 50 -j ACCEPT
iptables -A FORWARD -p tcp --syn -j DROP

# 4. Service Whitelisting
iptables -A FORWARD -s 10.10.1.0/24 -d 10.10.2.80 -p tcp --dport 80 -j ACCEPT
iptables -A FORWARD -s 10.10.1.99 -j DROP
